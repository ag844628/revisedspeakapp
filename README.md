# Companion (newspeakapp)

Voice companion and profile manager with Marathi Text-to-Speech (TTS), custom voice playback, audio recording, and background listening service.

## Features
- **व्हॉईस असिस्टंट डॅशबोर्ड (Voice Assistant Dashboard)**: Interactive profile manager with Material-inspired styling.
- **बॅकग्राउंड लिसनिंग सर्व्हिस (Background Listening Service)**: Active microphone audio meter and speech recognition listening.
- **प्रोफाइल व्यवस्थापन (Profile Management)**: Create and manage companion profiles with name, gender, age, profession, and relationship.
- **मराठी आवाज व भाषण (Marathi Voice & Speech)**:
  - Marathi Text-to-Speech greeting with gender-specific pitch regulation.
  - Custom audio upload and direct in-app voice recording saved and persisted across sessions.
- **मोबाईल इन्स्टॉलेशन (Mobile & PWA Ready)**: Installable directly on Android devices and home screens without APK downloads.
